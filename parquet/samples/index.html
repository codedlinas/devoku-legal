How to Use

  1. Click any file above to download it to your Mac.
  2. Open Devoku Parquet from your Applications folder (or Launchpad).
  3. Click the Open Parquet File button inside the app, then select the downloaded .parquet file.
  4. The file's data will load instantly — browse columns, sort, and explore the data.

Tip: You can also drag and drop a .parquet file directly onto the Devoku Parquet icon in your Dock.
